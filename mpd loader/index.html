💡 CORS & Local Playback Tips

If streams fail to load, it is usually due to CORS policy on the hosting server.

  • Local Files: Browsers block loading file paths (e.g. C:/...) directly. Run a local web server (like http-server or VS Code Live Server) to host your files.
  • CORS Extensions: For quick testing of external MPDs, you can install a "CORS Unblock" extension in Chrome/Firefox.
  • CORS Headers: Ensure the server hosting your MPD responds with Access-Control-Allow-Origin: *.
